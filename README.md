# Kayıp Çorapların Sonsuz Yolculuğu

## Bu Ne?

Bu, insanlık tarihinin en ciddi, en bilimsel ve en anlamsız projesidir. Her yıl milyonlarca çorap kaybolur. Nereye giderler? Neden? Nasıl?

Bu simülatör, kayıp çorapların kaderini hesaplar. Gerçekten çalışır. Sonsuza kadar. Çünkü çoraplar asla bitmez.

### Nasıl Kullanılır?

```bash
python corap_simulator.py
```

Çıktıyı izleyin. Düşünün. Ağlayın. Tekrar başlatın.

### Özellikler

- Sonsuz döngü (bu bir bug değil, özellik)
- Rastgele kaderler
- Gerçek zamanlı çorap sayacı
- Felsefi derinlik (opsiyonel)
- Hiçbir şey çözmez

### Uyarı

Bu program bilgisayarınızı çorapla doldurmaz. Sadece zihninizi doldurur.
